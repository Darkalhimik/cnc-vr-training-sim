# Haas UMC-500 / UMC-500SS – machine data for the digital twin

This file is the spec for the physical machine: travels, the B/C trunnion, kinematics and MRZP, spindle, feeds, tool changer, platter, utilities and the 5-axis control features. Developers build the machine model, kinematic chain and soft limits from it. Keys are in `pendant.md`, procedures in `operation.md`, code semantics in `gcode.md` / `mcode.md`, and setting/alarm lists in `settings-alarms.md`. This file only touches those topics where they affect the machine model.

Units are metric first, with the Haas inch value in [brackets]. Haas rounds its metric conversions. Where the exact conversion differs, both are shown. Data retrieved 2026-10-29.

## 4. Axis conventions, machine home and the kinematic chain

### 4.1 Machine coordinates and home

- Machine home is found from the home switches at `[POWER UP]` / zero return ([OM20] Operation chapter).
- "The X and Y work coordinate offsets are always given as negative values from machine zero" ([OM20] p. 244). Machine zero is therefore the positive end of each linear travel, and every reachable machine position is ≤ 0.
- During a tool change the control moves Z to machine zero or slightly above it, never below. At the end of the change Z is at machine zero ([OM20] §5.5.2).

| Axis | Machine zero (home) | Reachable machine coordinates | Status |
|---|---|---|---|
| X | +X end of travel | 0 … −610 mm [0 … −24.0 in] | DER from [OM20] p. 244 and [UMC20] T1.1 |
| Y | +Y end of travel | 0 … −406 mm [0 … −16.0 in] | DER, same basis |
| Z | Top of travel. The spindle nose is about 508 mm [20 in] above the platter face at B0. | 0 … −406 mm. At Z −406 the nose is about 102 mm [4 in] above the platter. Tool change goes slightly above 0. | DER from [UMC20] T1.1 and [OM20] §5.5.2 |
| B | 0° = platter horizontal, face up | −35° … +120° | OFF [UMC20] |
| C | 0° = home mark | unlimited, accumulating | OFF [UMC20] §7.1 |

**Machine architecture (DER from [UMC20] fig. F1.2):** The figure draws the X arrow on the column base, the Y arrow on the spindle-head ram and the Z arrow on the head. The trunnion sits fixed on the base. All three linear axes therefore move the spindle, and the trunnion carries only B and C. If so, the commanded linear direction is the physical spindle direction, with no table reversal:

- +X moves the spindle to the operator's right.
- +Y moves it away from the operator, toward the column.
- +Z moves it up.
- At X0 Y0 the spindle is at the right-rear limit of its travel. At Z0 it is fully up.

Haas does not state the home corner in words, so it is marked UNCONF in §17.

### 4.2 Rotary axis orientation and sign

**The B axis is parallel to machine Y, so B rotates about Y.** This was in question in the brief and is now settled by four independent pieces of evidence:

1. Settings 255 and 257 locate the B tilt-axis centreline by its X and Z distances from home. Setting 256 locates the C axis by its Y distance. A line parallel to Y is fixed by X and Z alone. Source: [OM20] pp. 468–470; [UMC20] §3.3.
2. TCPC and DWO need the ANSI axis set, in which A, B and C rotate about X, Y and Z. The UMC runs B/C TCPC. Source: [OM20] pp. 234, 239.
3. In fig. F1.2 the B-axis centreline is drawn parallel to the Y arrow, with the large trunnion support housing at its rear (+Y) end. Source: [UMC20] p. 2.
4. Haas alignment procedures check "B-axis to Y-axis parallelism" and check the platter against the Y-Z plane at B +90° / −90°. Source: OFF-idx [SVC-ROT].

**The C axis** is the platter normal. At B0 it is parallel to machine Z.

**C sign:** "`C960.` … rotary axis turns 960 degrees clockwise" and "`G28 G91 C0.` … rotates 240 degrees counter-clockwise to home" ([UMC20] §7.1). So **+C turns the platter clockwise**. The text does not give the viewing direction. The C arrow in fig. F1.2 is consistent with clockwise as seen from above, i.e. from the spindle. Status: OFF (sign); DER (viewing direction).

**B sign:** The B arrow in fig. F1.2 is drawn at the front end of the axis. Its "+120°" end and its "−35°" end show that **+B turns the platter face toward −X** (the operator's left):

- At B+90° the platter face points to −X.
- At B−35° the face is tipped 35° toward +X.

This also matches the ISO/ANSI convention for table-carried axes, which C follows above: +B and +C turn the table the negative right-hand way about +Y and +Z, so the tool moves positively relative to the work. Status: **DER — verify on a real machine or against a Haas UMC CAM post before release.**

### 4.3 Kinematic chain for the twin (DER)

```
Machine frame M  : Haas machine coordinates of the spindle gauge line.
                   Origin = home (X0 Y0 Z0). +X right, +Y toward column (away from operator), +Z up.
                   Reachable values are <= 0 (see 4.1).
Pivot O          : (S255, S256, S257) = MRZP settings, in Setting 9 units.
                   O is the point where the B and C axes cross (C axis taken at B0).
                   Setting 254 (|value| <= 0.1 mm) is the B-to-C centre offset; ignore it or add it as an X offset of C.
Platter frame P  : origin O, axes parallel to M at B0 C0, z_P = platter normal (C axis).
Platter face     : plane z_P = -h, where h = height of the B axis above the platter face
                   (UMC-750 ~ 51 mm [2 in] per [OM20] p. 241 and fig. F9.9; UMC-500 UNCONF).

Point on platter / fixture / part, p_P  ->  p_M = O + Ry(-B) * Rz(-C) * p_P
Ry(t) = [[cos t, 0, sin t], [0, 1, 0], [-sin t, 0, cos t]]
Rz(t) = [[cos t, -sin t, 0], [sin t, cos t, 0], [0, 0, 1]]
Tool tip T_M = (X, Y, Z - L), with L = tool length from the gauge line (H offset). Tool axis = -Z_M.
```

To map this into three.js (right-handed, Y up), one consistent choice is `three = (X_M, Z_M, -Y_M)`. Then the operator stands on the +z side and looks toward −z. With that mapping:

- **cradle.rotation.z = +B** (radians, about a three-z axis through O). Check: the platter normal goes from +y to −x at B = +90°.
- **platter.rotation.y = −C** (clockwise seen from above).

### 4.4 Tool-change motion

- **Setting 247 OFF** (Haas "strongly recommends" OFF on the UMC-750, and the same collision logic applies to the UMC-500): Z retracts first, then X and Y move.
- **Setting 247 ON:** X, Y and Z move together. Collision risk with tilted parts is high.

Because X and Y move during the change, there is a fixed tool-change X/Y position. Its coordinates and the side of the SMTC are UNCONF. Programs normally end with `G53 Z0.` then `G53 B0. C0.` ([UMC20] §4–5 examples).

Sources: [OM20], [UMC20], [SVC-ROT].

### 5.3 Safe Zone (UMC software feature)

- **What it does:** prevents collisions between the spindle head / spindle nose and the C platter / trunnion body.
- **What it ignores:** the WIPS tool probe, coolant nozzles, workholding and the workpiece.
- **Defaults:** the default calibration stops the machine about 25 mm [1 in] before contact. It must be calibrated with the probe for proper use.
- **Setting 408** (Exclude Tool From Safe Zone, default OFF) decides whether the tool length is included.
- **Availability:** software 100.20.000.1200 and later.

Status: OFF-idx [SVC-MRZP], [SVC-OPS]. For the simulator this is a natural "soft collision" model: a stop envelope around the platter/trunnion body plus the tool.

### 6.2 Torque and power curve (8,100 / 10,000 rpm, 40-taper)

These values are read from Haas chart [TQ] p. 1 (metric version). Reading accuracy is about ±3 %. Haas prints on the chart: **"Values shown are 200% spindle load"**. Treat the curve as the short-term envelope. The published "122 Nm @ 2,000 rpm" equals the chart value at 2,000 rpm.

| rpm | Torque, Nm [ft-lbf] | Power, kW |
|---|---|---|
| 0–500 | ≈ 125 [≈ 92] | – |
| 2,000 | ≈ 121 [≈ 89] | ≈ 25 |
| 2,400 (knee) | ≈ 120 [≈ 88] | ≈ 30 |
| 3,000–7,500 | falls as 1/rpm | ≈ 33–35 (constant-power band; peak ≈ 35 kW at about 3,800 rpm) |
| 4,000 | ≈ 83 [≈ 61] | ≈ 35 |
| 6,000 | ≈ 53 [≈ 39] | ≈ 33 |
| 8,000 | ≈ 39 [≈ 29] | ≈ 32 |
| 10,000 | ≈ 29 [≈ 22] | ≈ 29 |

- The 12K chart ([TQ] p. 3) has the same shape. It reaches about 20 Nm [15 ft-lbf] and about 25 kW at 12,000 rpm.
- The 15K chart ([TQ] p. 4) has a knee near 2,800–3,000 rpm and peaks near 35 kW [≈ 48 hp at 200 %]. It reaches about 14 Nm [≈ 10.5 ft-lbf] and about 22 kW at 15,000 rpm.
